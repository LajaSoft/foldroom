# Development scope

- Active development targets the native Godot application.
- The web application is paused. Do not modify anything under `web/` unless the user explicitly requests a web change.
- Preserve existing web changes; do not revert them as part of this pause.
- Do not mirror Godot changes into the web application or update its bundled example automatically.
- Reading web sources and running existing web tests as a reference is allowed, provided this does not modify `web/`.
